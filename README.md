# Sc2Fla

Sc2Fla is a C++ tool that converts Supercell *.sc files to Adobe Animate *.fla

## Usage
```sc2fla input [args]```

| Argument | Description |
| --- | --- |
| `-h`, `--help` | Show help |
| `-g`, `--group <name>` | Convert only matching exports |
| `-t`, `--texture <file>` | Use an external texture |
| `-o`, `--output <dir>` | Output directory |
| `-x`, `--xfl` | Write an unpacked *.xfl folder |
| `-f`, `--fps <number>` | Set the frame rate |

## Requirements
- CMake
- Ninja
- C++20 compiler
